# Lemoine-OR Algorithms — MetaheuristicsPlatform identity

MetaheuristicsPlatform belongs to the same pure-algorithm visual family as ULSAlgorithms.

## Shared concept

The icon combines:
1. an algorithmic path progressing through decision nodes;
2. an A-like construction for “Algorithms”;
3. an orange transition arc representing state change, search and improvement.
